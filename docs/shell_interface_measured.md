# 外壳接口实测（2026-11-13，从模型包 2026-11-13 版实测）

> 用 trimesh 对 `01_奶蛙外壳.stl` 和 `02_店家无手body.stl` 做截面和射线测量得到。
> 坐标系 = 原壳 STL 坐标：前 = −Y，上 = +Z，壳底面 Z = 0，左右对称面 X = 0。
> 本文件纠正 `interface_spec.md` 里两处与实物不符的说法（见第 1 节）。

## 1. 与 interface_spec.md 不一致的地方

| interface_spec.md 写的 | 实测 |
|---|---|
| 胸口 1.54 寸圆屏，外壳上开 **Ø40** 窗 | 屏幕装在**底座正面**的方窗里（窗口 28×29.5 mm，240×240 屏）。外壳上没有屏幕窗结构，只要在底座正面这个窗口前方让出视线。屏幕模组本身是圆是方以实物为准（奶龙 Wiki 部件页写的是圆屏） |
| `04_左卡销.3mf` 含外壳/底座/卡销的**装配**关系 | 3MF 是**打印摆盘**（4 个零件平铺），没有装配信息。装配位置是用卡销通道和腔体反推出来的（见第 2 节） |
| 壳下沿与底座「卡口配合」 | 没有卡口：底座整个装进外壳腔体（四周 0.5 mm 间隙），靠左右两根卡销穿过外壳侧面凸台、插进底座侧面 Ø8 孔锁住 |

## 2. 底座在外壳里的位置

- 底座平移 **(−1.61, +6.66, 0)** 后正好落进腔体：腔体 X −36.61…33.39（宽 70.0），后壁 Y = 41.66，顶 Z = 42.5；底座 69×69×42，四周各 0.5 mm 间隙。
- 腔体前面是敞开的：底座正面（屏幕面）在 **Y = −27.84**。原壳在 Y = −28.34 处有一圈唇边压住电路板（官方说明「外壳前侧要压住电路板」）。
- 外壳从上往下扣到底座上，所以底座投影范围内、Z < 42.5 的地方不能有任何外壳材料。

## 3. 屏幕与正面开孔（底座正面，换算到外壳坐标）

| 开孔 | 位置 |
|---|---|
| 屏幕窗口 | X −15.61…12.39，Z 8.0…37.5（中心 X −1.61，Z 22.75） |
| 小孔 Ø≈1 | X 16.39，Z 27.25（用途待查：麦克风或传感器）。科鲸壳把屏框开口横向放宽，把它一起让出来，不单独开孔（避免两孔之间留薄筋） |

## 4. 卡销

- 外壳两侧各一条 **8.4×8.4 mm 方通道**，轴线 Y = 6.66，Z = 28.0，从腔体侧壁（X ≈ ±37）通到凸台端面（X = ±53.8）。
- 底座两侧 Ø8 圆孔，中心（底座坐标）Y = 0，Z = 28 —— 平移后正好与通道同轴。
- 卡销 24.4×13×13 mm：一头 13×13 帽，一头带倒钩的叉。帽在外侧，贴凸台端面；凸台端面外侧要留出 Ø≥19 的空间按卡销。

## 5. 底部

- 外壳底面与底座底面齐平（Z = 0）。电源开关（左）、BOOT（右）、Type-C（中）都在底座底面，从下面操作，外壳不能低于 Z = 0。

## 6. 原壳的重量基准（新壳不要偏离太多，SG90 开环步态怕重心变化）

- 体积 386.1 cm³，表面积 513 cm²，重心 (0.1, 4.3, 56.6)。按 1.2 mm 外壁 + 15% 填充估算约 148 g。
- 上部（Z > 42.5）是实心造型，打印靠切片填充减重。
